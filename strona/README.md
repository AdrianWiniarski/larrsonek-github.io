# Moja osobista strona

## Start
Otwórz `index.html` w przeglądarce. Nie trzeba instalować bibliotek ani wykonywać kompilacji.

## Edycja
Najważniejsze treści i ścieżki zdjęć są w `assets/js/tresci.js`.
Układ poszczególnych stron: pliki `.html`. Kolory i odstępy: `assets/css/style.css`.
Dla własnych tytułów w wynikach wyszukiwania zmień również `<title>` i opis `meta name="description"` w każdym HTML.

Pełna instrukcja jest w pliku `INSTRUKCJA.html` obok folderu `strona` w pobranym archiwum.

## GitHub Pages
Wgraj ZAWARTOŚĆ tego folderu do głównego katalogu publicznego repozytorium `twojlogin.github.io`.
`index.html` i folder `assets` muszą być widoczne obok siebie w zakładce Code.
Następnie: Settings → Pages → Deploy from a branch → main → /(root) → Save.
Nie wgrywaj archiwum ZIP jako strony. Nie dodawaj fikcyjnej domeny do pola Custom domain.

## Prywatność
To publiczna witryna i publiczne repozytorium. Nie umieszczaj haseł, tokenów, adresu domowego ani prywatnych dokumentów.
Projekt nie zawiera zewnętrznych fontów, analityki, formularzy zbierających dane ani własnych cookies.
Kontakt jest linkiem mailto, nie wysyłką realizowaną przez serwer.
Zdjęcia zastępcze są prostymi grafikami SVG — nie przedstawiają prawdziwych osób ani wydarzeń.
